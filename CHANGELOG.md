# Changelog

## 0.1.0

First public TOPO release, based on User Wavetable 0.1.0-dev.6.

- Promotes the tested oscillator, M1 display and single-cycle browser audition to the stable release. Existing projects and installed layouts use the same `userwt` identity, parameter order and asset paths.
- Includes the Glass and Reed presets and a reproducible 32-cycle Vowel-256 bank for the user sample browser.
- Includes the three checked SDK patches, host tests, standalone build instructions and a TE Builder source ZIP.
