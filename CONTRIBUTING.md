# Contributing

Use the pinned Open-XY revision in the [build guide](docs/BUILDING.md). For changes to sound or drawing, run the SDK machine test, PCM/surface test and selector test. Regenerate the release ZIP when its inputs change.

For an issue, include the TOPO version, XY OS version, SDK revision and the steps that reproduce it. For a table issue, include the K1 setting, WAV format, channel count, samples per cycle and active trim. If possible, attach a small WAV you can share. For browser audition issues, mention whether they occur on highlight, on confirmation or when playing a note.
